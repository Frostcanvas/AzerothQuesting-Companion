# Azeroth Questing Companion

Azeroth Questing Companion is the Windows desktop companion for the Azeroth Questing World of Warcraft addon.

It helps manage addon installation and updates, monitor locally collected quest observations, and synchronize eligible research data with the Azeroth Questing Server.

## Current development release

The current development train is **0.1.9 Beta 5** (`0.1.9-beta.5`).

See `CHANGELOG.md` for the authoritative release history and current testing requirements.

## Update channels

- **Stable** only uses normal public GitHub Releases.
- **Beta** can use eligible GitHub Pre-releases as well as newer Stable releases.
- Addon and Companion versions advance independently.

## Windows installation

Published installers use the updater-visible filename:

`AzerothQuestingCompanion-Setup.exe`

Beta prereleases may temporarily be unsigned while trusted code signing is unavailable and can trigger Windows SmartScreen or publisher warnings. Stable Companion releases must be signed.

## Azeroth Questing Server

The Companion uses the public Azeroth Questing Server endpoint for supported synchronization features. Private FrostLabs infrastructure details are not player-facing.
